### 2. 🔮 August 2026 Design Paradigms

- **Liquid Chromatic Glassmorphism 2026**: Multi-layer `backdrop-filter: blur(24px) saturate(190%)`, 1px sub-pixel inset specular border highlights (`box-shadow: inset 0 1px 1px 0 rgba(255,255,255,0.4)`), and dynamic chromatic edge dispersion.
- **Inertial Multi-Plane Parallax**: GPU-accelerated CSS scroll-driven animations (`animation-timeline: scroll()`) and pointer spring-physics micro-tilts with 4 discrete depth channels (0.10 ambient, 0.25 badges, 0.50 cards, 0.85 foreground).
- **Spatial Bento 3.0**: Container-query responsive grid matrices with pointer-tracking radial spotlight glows and spring-physics tile morphing.
- **Dark OLED Luxe 2.0**: Absolute `#08090E` backgrounds with high-gamut OKLCH neon halos and 16.8:1 text contrast.
- **W3C DTCG Standard Design Tokens**: Standard `$value` and `$type` token files with instant export to Tailwind v4 `@theme`, CSS Custom Properties, and TypeScript definitions.

## 📦 Installation & Quick Start

### Option 1: Global CLI (Recommended)

```bash
# Install globally via npm
npm install -g uipro-cli

# Initialize for your AI assistant in your project directory
uipro init --ai claude      # Claude Code
uipro init --ai cursor      # Cursor IDE
uipro init --ai windsurf    # Windsurf
uipro init --ai all         # All 14+ assistants at once!
```

### Option 2: Universal Model Context Protocol (MCP) Server

Connect UI/UX Pro Max to **Cursor, Claude Desktop, Windsurf, Cline, or Zed** via MCP:

Add to your `claude_desktop_config.json` or Cursor MCP settings:

```json
{
  "mcpServers": {
    "ui-ux-pro-max": {
      "command": "python3",
      "args": ["/path/to/ui-ux-pro-max-skill/src/ui-ux-pro-max/scripts/mcp_server.py"]
    }
  }
}
```

Exposed MCP Tools:
- `run_multi_agent_design_pipeline`: End-to-end design orchestration.
- `generate_design_tokens`: W3C DTCG tokens & Tailwind v4 `@theme`.
- `search_ui_intelligence`: BM25 search across 73+ styles, typography, and UX guidelines.
- `audit_ui_accessibility`: Automated WCAG 2.2 AAA accessibility check.

## ⚡ CLI Command Reference

### 1. Multi-Agent Design Orchestration

```bash
# Run full 6-agent design pipeline with persistence
uipro agent "Build a luxury fintech dashboard with liquid glass and parallax" -p "Titan Vault" --persist

# Target specific stack (react, nextjs, vue, svelte, swiftui, flutter)
uipro agent "E-commerce fashion showcase" --stack react --persist
```

### 2. Design Tokens Generator (W3C DTCG Standard)

```bash
# Generate complete design tokens (W3C JSON, CSS Variables, Tailwind v4 @theme, TypeScript)
uipro tokens --primary "#6366F1" --secondary "#06B6D4" --cta "#10B981"

# Export specific format
uipro tokens --primary "#6366F1" --format css
uipro tokens --primary "#6366F1" --format tailwind
uipro tokens --primary "#6366F1" --format ts
uipro tokens --primary "#6366F1" --format w3c
```

### 3. Live Design Studio Web Workbench

```bash
# Launch live interactive design studio & REST API
uipro serve --port 8080
```

Open `http://localhost:8080` in your browser to:
- Visually test and orchestrate multi-agent prompts in real time.
- Adjust 2026 liquid glass blur, saturation, specular highlights, and 3D parallax depth shaders interactively.
- Inspect and copy W3C DTCG tokens and generated component code with 1 click.

## 🛡️ Pre-Delivery Quality Checklist (August 2026 Standards)

- [x] **No Emoji Icons**: All UI icons use vectorized SVG paths (Lucide / Heroicons) with 24x24 viewBox.
- [x] **Sub-Pixel Specular Glass**: `backdrop-filter: blur(24px) saturate(190%)` with inset border reflection.
- [x] **Hardware-Accelerated Parallax**: Pure CSS scroll-driven animations with `translate3d` and `will-change`.
- [x] **WCAG 2.2 AAA Contrast**: Text contrast ratio strictly >= 7.0:1 on all surfaces.
- [x] **Zero CLS**: Container query fixed aspect ratios prevent layout shifts during interaction.
- [x] **Reduced Motion Fallback**: `@media (prefers-reduced-motion: reduce)` resets transforms and animations.
- [x] **Cursor Feedback**: `cursor-pointer` applied on all interactive cards, pills, and action items.
